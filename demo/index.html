Integration Guide

HexPic can be used as a drop-in HTML plugin or imported as an ES module in modern frameworks like React, Next.js, and Vite.

1. Declarative HTML Plugin

Add data-hexpic to any image element and call HexPic.init():

<script src="https://cdn.jsdelivr.net/npm/hexpic/dist/index.umd.js"></script> <img src="avatar.png" data-hexpic data-hexpic-width="100" data-hexpic-dithering="atkinson" /> <script> HexPic.init(); </script>

2. TypeScript & Modern Frameworks

Install via npm and import the engine or React components:

import HexPic from 'hexpic'; const converter = new HexPic({ width: 100, dithering: 'atkinson', charset: 'blockelement', colorMode: 'color' }); const result = await converter.fromUrl('/avatar.png'); console.log(result.ascii); document.getElementById('art').innerHTML = result.html;
